# 石景山 UI 规范

当用户要求为“石景山AI产业服务平台”新建页面、优化页面、调整组件样式，或明确说“按 UI 规范 / 按 PDF 规范 / 按石景山设计规范 / 按 shijingshan 主题”处理时，使用这个 skill。

## 规范来源

来源：`public/石景山AI产业服务平台设计规范(2).pdf`。

PDF 包含移动端与 Web 端两套规范：

- 移动端：基于宽度 `430px`、`@2x` 设计稿提炼，开发尺寸按标注值直接使用。
- Web 端：基于 `1920x1080`、`@2x` 设计稿提炼，开发时建议按 `1 CSS px = 2 设计稿 px` 换算。

## 设计气质

石景山主题整体应该保持清爽、可信、数据化、偏产业服务平台的气质。页面以浅色背景和白色卡片承载信息，用蓝色表达关键操作、选中态、图表主色和链接。导航可使用深蓝灰底色，形成清晰的信息工作台感。

## 布局规范

### 移动端

- 基础宽度：`430px`。
- 页面左右边距：`16px`。
- 内容区宽度：约 `398px`。
- 尺寸单位：使用 `px`，`@2x` 设计稿标注值直接用于开发。
- 布局方式：使用 `Flex` 或 `Grid`，间距使用固定值，保证不同屏幕下内容稳定。

### Web 端

- 页面基准宽度：`1920px`。
- 左侧导航栏：设计稿 `480px`，CSS `240px`，背景色 `#1E293B`，高度 `100vh`。
- 右侧主内容区：自适应剩余宽度，背景色 `#F9FAFB`，内边距设计稿 `48px 24px`，CSS `24px 12px`。
- 内容最大宽度：设计稿 `1440px`，CSS `720px`，超出时可居中或留白。
- 栅格系统：采用 `24` 列栅格，CSS 左右边距 `24px`，CSS 列间隔 `16px`。
- 小屏适配：当屏幕宽度小于 `1440px`，可缩小边距或减少栅格列数。
- 导航收缩：导航栏可收缩为图标模式，宽度设计稿 `80px`，CSS `40px`。

## 组件规范

### 卡片

- 背景色：`#FFFFFF`。
- 圆角：`12px`。
- 内边距：移动端 `16px`，Web 端 CSS `16px`。
- 阴影：`0 2px 8px rgba(0,0,0,0.05)`。
- 构成：通常包含标题、数值、描述、图表或列表。
- 标题区域：Web 端标题 `18px/600`，可选“查看更多”文字按钮 `14px/400`，使用主色。
- 内容间距：上下元素间距 `12px`。

典型场景包括企业概览卡片、补贴卡片、数据指标卡片、图表卡片和平台资讯卡片。

### 按钮

| 类型     | 高度                          | 圆角       | 文字样式   | 背景色     | 文字色         | 边框                |
| -------- | ----------------------------- | ---------- | ---------- | ---------- | -------------- | ------------------- |
| 主按钮   | 移动端 `44px`，Web CSS `40px` | `8px`      | `16px/500` | `#2A6DF4`  | `#FFFFFF`      | 无                  |
| 次按钮   | 移动端 `44px`，Web CSS `40px` | `8px`      | `16px/500` | 透明或白色 | `#2A6DF4`      | `1px solid #2A6DF4` |
| 文字按钮 | 自适应                        | 无固定圆角 | `14px/400` | 透明       | 次要文字或主色 | 无                  |

按钮内边距：移动端水平 `16px`、垂直 `12px`；Web 端 CSS 水平 `16px`、垂直 `8px`。

### 标签

- 高度：`24px`。
- 内边距：水平 `8px`。
- 背景色：移动端 `#F2F4F7`，Web 端 `#F1F5F9`。
- 文字色：移动端 `#374151`，Web 端 `#334155`。
- 圆角：`4px`。
- 字号：`12px`，字重 `500`。
- 带图标标签：移动端图标 `16x16`，Web 端 CSS 图标 `12x12`，图标与文字间距 `4px`。

### 列表与表格

移动端列表：

- 列表项高度：`48px` 到 `56px`，可包含标题、描述、右侧数值。
- 分割线：`1px solid #EEF2F6`，左右留边 `16px`。
- 表格列表行高：`40px`，文字 `14px`，列间距自适应。

Web 端表格：

- 行高：CSS `40px`。
- 文字：`14px/400`。
- 表头：背景 `#F9FAFB`，文字次要色，字重 `500`。
- 分割线：底部 `1px solid #E5E7EB`。
- 内边距：左右 CSS `8px`。
- 斑马纹：可选，隔行浅灰背景。

企业经营数据列表：

- 每项两列，左侧项目名 `14px/400`，右侧数值 `14px/600`。
- Web 端行高 CSS `28px`，底部分割线。

### 图表

- 柱状图 / 条形图：移动端柱高 `4px` 到 `8px`，Web 端 CSS 柱高 `12px` 到 `20px`。
- 柱状图圆角：`4px`。
- 图表主色：`#2A6DF4`。
- 图表辅助灰：Web 端 `#E5E7EB`。
- 折线图：线宽 `2px`，点直径 `6px`，主色蓝色。
- 环形图：Web 端 CSS 直径 `80px`，线宽 `8px`。
- 环形图 / 饼图：使用主色及辅助色系列，避免颜色过多导致信息噪声。

### 导航与标题

移动端：

- 页面标题：`22px/600`，左侧可带 `24x24` 返回图标，下方可跟 `14px/400` 描述文字。
- 板块标题：`18px/600`，右侧可带“查看更多”文字按钮，文字按钮 `14px/400`，使用主色。

Web 端左侧导航栏：

- 宽度：CSS `240px`。
- 背景色：`#1E293B`。
- 内边距：CSS `12px 8px`。
- Logo 区域：CSS 高度 `40px`，包含平台名称和英文描述；平台名称白色，英文描述使用辅助文字色。
- 菜单项：CSS 高度 `32px`，内边距 `8px 4px`，圆角 `4px`。
- 菜单文字：默认白色，CSS `14px`。
- 菜单图标：CSS `16x16`。
- 悬停 / 选中：背景色可使用 `#2A6DF4` 或 `#334155`，文字加粗。
- 底部个人信息：沿用菜单项样式，可收缩。

### 常用智能体网格

移动端：

- 每行 `4` 个，间距 `16px`。
- 图标尺寸：`40x40` 或 `48x48`。
- 下方文字：`12px`，居中对齐。
- 整体容器左右边距：`16px`。

Web 端：

- 每行 `6` 到 `8` 个，居左排列。
- 图标尺寸：CSS `32x32`。
- 下方文字：`12px/400`。
- 图标间距：水平 CSS `12px`，垂直 CSS `16px`。

### 数据指标卡片

- 样式：紧凑型卡片。
- 内边距：移动端 `12px`，Web 端 CSS `12px`。
- 指标名称：`14px/400`，使用次要文字。
- 指标数值：移动端 `20px` 到 `28px`、`600`；Web 端 `28px/600`。
- 变化率：`12px`，上升用 `#10B981`，下降用移动端 `#F43F5E` 或 Web 端 `#EF4444`，可带箭头图标。
- 去年对比：Web 端 `12px`，使用辅助文字。

### 平台资讯 / 新闻列表

- 每项结构：左侧类别标签，标题、描述，右侧时间及阅读量。
- 标题：`14px/600`。
- 描述：`12px/400`，使用次要文字。
- 时间：`12px/400`，使用辅助文字。
- 缩略图：移动端 `40x40`，Web 端 CSS `40x40`，圆角 `4px`。
- 分割线：移动端 `#EEF2F6`，Web 端 `#E5E7EB`。

## 页面布局示例

### 移动端首页

- 顶部：平台标题 + 企业信息，包含企业名称、描述、产业标签、访问天数。
- 补贴卡片：大卡片，包含标题、描述、按钮。
- 常用智能体：`8` 个网格图标。
- 企业概览：双栏指标，包含智能体数据、资源数据和图表。
- 平台资讯：列表形式，最后一条可带“查看更多”。

### 移动端数据页

- 顶部：三个等宽数据卡片，展示企业数、营收、税收。
- 产业标签：一行滚动标签，约 `5` 个。
- 企业经营数据：列表，左右两列，项目名 + 数值。
- 排名表格：左右结构，展示地区、数量、注册资本。
- 产业链环节：环形图 + 百分比。
- 数据集分布：条形图列表。

## 落地建议

- 优先沿用项目已有的 shijingshan 主题样式文件和组件结构，再补充缺失 token。
- 页面背景保持浅灰，内容承载尽量使用白色卡片，不要把整页做成大面积蓝色。
- 蓝色主色用于关键交互、选中态、图表主系列和链接；警示、成功、错误色只在语义明确时使用。
- 卡片阴影保持克制，使用 `0 2px 8px rgba(0,0,0,0.05)`。
- 数据类页面要保持信息密度和可扫描性，避免过度装饰。
- 移动端至少检查 `430px` 设计基准和常见 `375px` 宽度，确保文字不溢出、不遮挡按钮。
- Web 端检查左侧导航、主内容宽度、卡片栅格和表格行高在常见桌面宽度下是否稳定。
