# sybz-sidebar-star

## 展示要求

1. 在左侧侧边栏指定条目前添加醒目的红色星号标志。
2. 星号放在文字前面。
3. 星号样式要圆润、醒目、好看。
4. 只给下面列出的函数、组件或指令添加星号，不要标记其他条目。

## 标记范围

### 函数方法

- `$toast`
- `clone`
- `confirm`

### Basic 基础组件

- `button`
- `dialog`
- `input`
- `tooltip`

### 原生组件

- `flex`
- `basicLayout`

### Complex 复杂组件

- `form`
- `table`

### 业务组件

暂无。

### 自定义指令

- `focus`
- `debounce`
