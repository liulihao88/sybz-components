01 · DESIGN POSITIONING

设计定位与核心原则

前端门户面向城市服务使用者，强调公开展示、业务理解和行动转化；后台控制台面向运营、审批和管理人员，强调信息扫描效率、操作确定性和持续使用的舒适度。

深色能力页基准 frontend/pages/capability-hub.html
深色 AI Banner、能力卡、紫色高亮
后台登录基准 admin/pages/login.html

后台总览基准 admin/pages/console-overview.html
侧导航、指标卡、主面板、数据图表

政务可信

秩序清楚、信息透明、文案准确。用克制的蓝白层级建立可靠感，避免夸张营销表达。

AI 科技

以蓝青渐变、数据感图形和沉浸式深色场景表达能力感；科技元素服务于信息，不喧宾夺主。

城市服务

用可理解的场景、应用和行动入口组织内容，让用户快速知道“能做什么、下一步怎么做”。

统一原则：同类页面、组件和状态必须使用同一视觉规则；新增页面优先复用现有色值、字号、圆角、导航和按钮，而不是单独创造一套风格。

03 · LAYOUT SYSTEM

布局、间距与视觉承载

门户页面

  • 内容最大宽度 1200px ，两侧内边距 24px 。
  • 页头、页脚可扩展至 1420px 宽承载。
  • Section 推荐上下内边距 54px 24px 。
  • 场景卡桌面 4 列、能力卡 3 列，平板 2 列、移动端 1 列。

后台控制台

  • 采用左侧固定导航 + 右侧内容布局。
  • 导航宽度 252px ，主内容最小宽度 1024px 。
  • 主内容推荐内边距 26px 30px 40px 。
  • 总览指标卡和主面板当前使用 16px 圆角；登录卡片使用 18px ，输入框/按钮使用 10px - 12px 。

间距与表面规则

层级 数值 主要用途 表面表现
微间距 4px / 8px 图标与文字、标签、按钮内部 紧凑但不拥挤
常规间距 16px / 24px 卡片内部、模块内元素 信息块边界清楚
模块间距 32px / 48px / 64px 标题与内容、页面分区 形成稳定阅读节奏
圆角与阴影 门户/能力页 8px ；后台面板 16px 卡片、图片、面板 门户使用柔和蓝色投影；能力页使用深色阴影与微光

04 · COMPONENTS

基础组件标准

按钮、标签与卡片

查看 AI 能力 申请试用 停用服务

主按钮

最小高度 42px ，左右内边距 18px ，圆角 10px 。同一区域最多一个主按钮。

次级与危险操作

次操作用描边或浅底；删除、停用、驳回使用危险色并配合二次确认。

门户卡片

白色承载面、 8px 圆角、低对比蓝灰边框；Hover 上移 3px 并加强阴影。

标签

只表达类型、能力、状态和关键词，不承担主要操作。单张卡建议 2 - 4 个标签。

导航与页头

  • 门户导航高度 92px - 106px ，白色半透明背景，当前项用蓝色下划线或浅底。
  • 后台导航项高度 42px ，图标常用 18px ，激活态为浅蓝底和蓝色文字。
  • 品牌区保持图形与文字标识，移动端可隐藏副标题但不隐藏主标识。

表格、表单与弹窗

  • 表格提供必要的搜索、筛选与状态标签，操作列右侧固定且不超过 3 项。
  • 输入框高度 40px - 44px ，聚焦态使用主品牌蓝，错误紧贴字段展示。
  • 常规弹窗宽度 520px - 720px ，底部按钮右对齐，主按钮在右。

07 · INTERACTION & RESPONSIVE

交互、状态与响应式

Hover 与选中

可点击按钮、卡片和导航需有明确反馈。按钮可上移 1px；卡片可上移 3px；当前导航必须有蓝色文字、下划线或浅蓝底。

加载、空与错误

提交时防止重复点击；表格加载显示骨架或加载提示；空状态必须说明原因和下一步；错误应说明影响与可采取动作。

可访问性

主要按钮不低于 40px；不只用颜色表达状态；图片承担信息时提供 alt；焦点态不得被完全移除。

响应式降级路径

桌面端 门户 3 - 4 列
后台完整侧导航
平板端 门户 2 列
导航可滚动或折行
移动端 门户 1 列
后台改抽屉或横向表格
移动端不得存在横向溢出；文字在按钮、卡片、表格单元格中必须保持可读，必要时换行或截断，不直接按视口宽度缩放字号。

08 · DELIVERY RULES

开发、预览与发布规范

前端门户源文件 frontend/pages/
frontend/assets/
frontend/colors_and_type.css
后台管理源文件 admin/pages/
admin/assets/
admin/colors_and_type.css
开发预览首页 http://localhost:5173/frontend/pages/home.html
以此地址作为门户验收基准。
发布产物目录 vue-dist/
修改源文件后执行 npm run build ，发布该目录内容。

源文件修改原则

  • 门户改动优先落在 frontend/pages/ ，后台改动优先落在 admin/pages/ 。
  • 公共色值、字号和圆角优先复用现有 colors_and_type.css 。
  • vue-dist/ 为构建产物，不作为日常源文件维护。
  • home-current.html 仅保留兼容用途，不作为新门户入口。

页面验收清单

色彩、字号、圆角、阴影一致
图片清晰且不变形
导航、按钮、状态可识别
无元素重叠和文字溢出
桌面、平板、移动端布局正常
打包后入口为 home.html
