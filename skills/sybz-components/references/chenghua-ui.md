# 成华 UI 规范

当用户要求为“成华区AI产业服务平台”新建页面、优化页面、调整组件样式，或明确说“按 UI 规范 / 按 PDF 规范 / 按成华设计规范”处理时，使用这个 skill。

## 规范来源

来源：`成华区AI产业服务平台 UI 设计规范（web端+移动端）`，版本 `1.0`。

## 设计变量

### 颜色

- 主色：`#165DFF`，用于主按钮、重要标签、选中态、高亮入口。
- 辅助渐变色：`#1E6EFC` 到 `#00C5E7`，用于 banner、重点卡片背景、数据强调区域。
- 标题文字：`#000000`。
- 正文文字：`#000000`。
- 辅助文字：`#979797`，用于次要信息、提示文字、占位文字、弱化说明。

整体应该以白色或浅色背景为主，用蓝色表达重点状态。渐变色不要到处铺，只用于关键入口、重点数据、banner 或需要强化视觉层级的区域。

### 字体

中文界面文字使用 `PingFang SC, sans-serif`。数字指标、统计数据、金额、计数类内容使用 `Roboto Mono, monospace`。

Web 端基准宽度：`1280px`。

- 页面主标题：字重 `600`，字号 `40px` 或 `36px`，行高 `1.4`。
- 模块标题 / 副标题：字重 `500`，字号 `20px`，行高 `1.5`。
- 正文大号：字重 `400`，字号 `16px`，行高 `1.6`。
- 正文小号 / 辅助说明：字重 `400`，字号 `14px`，行高 `1.5`。
- 数字 / 指标：字重 `600`，字号 `24px`，行高 `1.4`，使用等宽字体。
- 按钮文字：字重 `500`，字号 `16px` 或 `14px`，行高 `1`。

移动端基准宽度：`375px`。

- 页面主标题：字重 `600`，字号 `28px`，行高 `1.4`。
- 模块标题 / 副标题：字重 `500`，字号 `20px`，行高 `1.5`。
- 正文大号：字重 `400`，字号 `16px`，行高 `1.6`。
- 正文小号 / 辅助说明：字重 `400`，字号 `14px` 或 `12px`，行高 `1.5`。
- 数字 / 指标：字重 `600`，字号 `24px`，行高 `1.4`，使用等宽字体。
- 按钮文字：字重 `500`，字号 `16px`，行高 `1`。

## 组件规范

### 按钮

- 主要按钮：高度 `44px`，圆角 `8px`，左右内边距 `20px`，文字 `16px`。
- 次要按钮：高度 `36px`，圆角 `8px`，左右内边距 `16px`，文字 `14px`。
- 文字按钮：高度自适应，圆角 `0`，左右内边距 `8px`，文字 `14px`。

主要按钮使用 `#165DFF`。按钮需要有清晰的 hover、active、disabled 状态。按钮内图标和文字之间的距离按 `8px` 网格控制。

### 卡片

移动端卡片参考尺寸，可以根据内容做适当调整：

- 数据卡片：宽 `280px`，高 `120px`，圆角 `12px`，内边距 `20px`，轻微悬浮阴影。
- 服务入口卡片：宽 `280px`，高 `100px`，圆角 `12px`，内边距 `16px`，轻微悬浮阴影。
- 推荐卡片：宽 `280px`，高 `140px`，圆角 `12px`，内边距 `20px`，轻微悬浮阴影。

Web 端卡片宽度按栅格和容器自适应，但建议保持 `12px` 圆角、`16px` 或 `20px` 内边距，以及轻微阴影。后台类、工具类页面要克制，不要做得过度装饰化。

### 图标与图片

Web 端：

- 功能图标：`16px` 到 `24px`，线性或面性，使用主色，用于服务入口、导航等。
- 指标图标：`20px` 或 `64px`，面性图标，使用辅助色，用于数据看板。
- 推荐图标：`40px`、`42px` 或 `48px`，圆角矩形，浅色背景，用于推荐卡片。
- 头像 / 标识：`32px`，圆形，可带边框。

移动端：

- 功能图标：`24px`，线性或面性，使用主色。
- 指标图标：`20px`，面性图标，使用辅助色。
- 推荐图标：`48px`，圆角矩形，浅色背景。
- 头像 / 标识：`40px`，圆形，可带边框。

## 布局与间距

间距系统基于 `8px` 网格。

- 模块间距：`32px`，用于模块与模块之间。
- 卡片间距：`24px`，用于卡片与卡片之间。
- 内容间距：`16px`，用于卡片内部元素之间。
- 小间距：`8px`，用于标签、图标、文字之间。

响应式设计时，桌面端以 `1280px` 为基准，移动端以 `375px` 为基准。使用有最大宽度约束的容器、弹性网格和断点样式，不要用视口宽度直接缩放字体。

## 落地建议

- 先看项目里已有组件和样式，优先沿用现有模式，再决定是否新增抽象。
- 如果当前模块已经有 CSS 变量或设计 token，就把这些颜色、圆角、间距沉淀进去。
- 平台气质应保持：清爽、可信、偏 AI 服务、以蓝色为主、信息层级明确。
- 渐变色只用于高价值区域，不要整页都堆渐变。
- 卡片要易读、实用，层级清楚，留白适中，阴影克制。
- 移动端至少检查 `375px` 宽度，确保文字不溢出、不遮挡、不挤压按钮。
- Web 端检查常见桌面宽度，避免卡片、标题、按钮在不同宽度下错位。
